The 14-Step Client Onboarding Checklist Freelancers Actually Use

Projects go wrong in week one or they don't go wrong at all. A repeatable onboarding sequence — same steps, every client — is what separates freelancers who scale from freelancers who firefight. Here is the checklist:

Before kickoff

  1. Signed agreement stored where you can find it (not email scroll).
  2. Deposit invoice sent and paid before any work starts.
  3. Project brief doc created with goals, deliverables, and dates.
  4. Shared channel agreed (one place, not five).
  5. Point of contact named on both sides.

Kickoff call agenda

  1. Introductions and roles.
  2. Walk the brief aloud; correct assumptions live.
  3. Confirm communication cadence (weekly update, day, format).
  4. Set review rounds and feedback windows in writing.
  5. Flag out-of-scope items early: "that's phase two."

First week

  1. Access and assets collected with a checklist (logos, accounts, logins via password manager).
  2. Project tracker shared so the client sees progress without asking.
  3. First milestone scheduled with a date, not "soon."
  4. Welcome packet sent: how you work, response times, invoice schedule.

Why this works

Every item above kills one classic failure mode: unpaid work (deposit first), scope creep (out-of-scope flagged at kickoff), ghosting (cadence set), chaos (one channel, one tracker). Onboarding isn't admin — it's the contract made operational.

FAQ

What if a client refuses the deposit? That is your cheapest possible red flag. No deposit, no start — ever.

How long should onboarding take? One kickoff call plus a week of setup. If it drags past two weeks, the project itself is mis-sold.
